开始使用与账户

搭建你的第一个 Agent

可以先试用配置好的公共 Agent，也可以从骨架逐个配置节点。模型、工具和知识库分别管理，再绑定到节点。

1 · 先体验一个 Agent

在工作台选用公共 Agent，回到对话页提出一个小任务。Fixed 按固定节点运行，Auto 自主迭代，Flow 先规划再执行。

选择 Agent →

2 · 选择模型来源

试用可以使用平台提供的模型。需要个人模型时，创建自己的连接，并明确是否允许辅助功能使用平台模型。

管理模型连接 →

3 · 配置并启用

为各节点选择模型、Prompt、Advisor 和 MCP 连接。修改先存为草稿，确认后启用；节点调试默认不执行工具。

进入 Agent 工作台 →

4 · 添加资料与验证

按需上传个人知识文档，等待入库成功，再用检索测试确认命中。绑定知识库后，执行一次实际任务并查看记录。

管理知识库 →
查看运行历史 →

用量和额度查看：个人用量。保存回答、导出表格或提供反馈：产物与反馈。反馈加入评测需要你明确选择。

修改登录密码

修改后需要重新登录，其他设备上的旧登录会话会在下次请求时失效。已在执行的任务不会因此自动重跑。
