# 运行历史、回放与通知

`/history.html` 仅展示已登录用户自己的运行。V067 新增 `ai_run_history`，保存问题、当次服务端绑定的 Agent 配置版本、策略、状态、最终回答和有上限的诊断事件。它独立于 Redis 重连事件和工具证据的有效期。

- 执行入口先插入唯一 runId，再开始路由和外部调用；Redis 过期不会使相同 runId 被再次执行。
- Agent 版本在执行租约内绑定。草稿编辑不会改变已经启用的版本。
- 最终回答来自写入对话记忆的用户可见正文，诊断 token 不被冒充为最终回答。
- 诊断最多保存 2,000 条、约 1 MiB 字符内容；单条过长会留下标注过截断的预览。最终回答单独保存。工具原文仍使用原先受归属和 TTL 控制的工具证据服务。
- 活跃进程每 30 秒续心跳。3 分钟没有心跳的 RUNNING 记录显示 INTERRUPTED，不会自动重放可能有外部副作用的操作。等待计划确认单独显示 BLOCKED。
- 数据库暂时故障时，已有执行的诊断写入可能不完整；页面不会声称保存了完整 HTTP 流或未实际发生的成功结果。
- `/outcomes.html?runId=...` 可从该次运行创建独立产物和反馈。复制复用是显式操作，不会自动把所有历史产物注入新任务上下文。

### 自动生成文档、表格和代码文件

模型通过同一个 `create_artifact` 工具保存产物。`MARKDOWN` 使用 `content.markdown`，下载为 `.md`；`TABLE` 使用 `content.columns` 和 `content.rows`，下载为 `.csv`；`CODE` 使用 `content.filename`、`content.language`、`content.code`，按原文件名下载单个源码文件。源码保留缩进和换行，在页面以纯文本预览，不执行代码，也不表示已经通过编译或运行验证。当前不生成多文件 ZIP。

示例请求：请生成一个读取 CSV 并按类别汇总金额的 Python 脚本，使用 create_artifact 保存为 summary.py，方便下载；说明使用方法。

生成中的阶段会显示“正在生成产物内容”；参数不合法时反馈 JSON 位置、字段要求和格式示例，并尝试一次修复。修复仍失败时，本次模型调用撤下产物工具，让模型直接提供正文并明确文件未保存，避免不断重写整个文件。成功保存后展示产物卡片；只有后端保存成功才会出现下载地址。不同运行与节点的恢复状态隔离，普通业务工具不因此禁用。

沿用 V069 的产物和版本表，不需要新增迁移。代码文件下载采用附件响应；文件名只允许单个文件名，不能包含目录或路径跳转。历史版本、所属用户和任务校验继续生效。

新历史从升级后开始记录；旧对话继续通过原会话列表查看，不虚构旧运行的配置版本或诊断事件。

## 会话与评测历史

普通会话和 EvalOps 会话均校验当前登录用户的归属。旧会话缺少登记时，从 MySQL 消息和持久运行历史核对一致归属，不按会话名前缀放行；管理员也不能借此读取其他用户会话。

`GET /api/v1/history/session/{sessionId}?offset=0&limit=50` 返回本人运行摘要，默认每页 50 条、最多 100 条。即使任务在写入聊天消息前失败或取消，仍可从持久历史读取已有状态和诊断。展开后再读取详细事件，旧计划和审批只读。快照缺失、Redis 失效或页面刷新不应把已经结束的步骤恢复为执行中；未保存的信息不伪装为完整记录。

FLOW 依赖标签与步骤正文在实时、确认计划后的续跑、历史回放中使用同一规则。回放按账户、会话、运行与事件身份去重；同名工具的新调用仍单独展示。迟到的 Token 可补充正文，不把终态改回运行中。

## 准备进度与运行上下文

SSE 可展示选择 Agent、准备 Agent、连接 MCP，以及 Advisor 的记忆检索、RAG 路由、检索与重排阶段。长等待显示已等待时间，不预测完成百分比，也不把心跳当作模型响应活动。这些临时进度不写入最终答案或持久诊断。

Advisor 在线程切换后继续传递可信的用户、运行和模型用途信息，辅助调用计入同一运行账本。取消和线程复用不会继承另一个用户的上下文。

## 收件箱

普通任务整体完成或失败会给本人发送去重通知；当前可见的对应任务可自动标为已读，其他任务或后台标签页保留未读。点击通知定位对应运行，快照过期时可回退到持久历史。

“全部已读”只修改本人通知的阅读标记，不确认计划、回答问题或批准工具。请求以时间截点处理保留通知，并跳过期间新增或更新的记录。通知沿用轮询机制，不包含系统推送或邮件。
